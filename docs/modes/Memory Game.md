# Memory Game

Memory Game is an individual, paced game mode. Protect from abuse does not apply.

## Question phase

Each question phase runs three paced questions. Each correct answer earns one chip. If nobody earns a chip, play the next question phase. Players with chips take their reveal turns in ascending order of average time on correct answers in the current question phase. For equal averages, favor the player who has gone first in fewer reveal phases, then the player who joined the lobby earlier.

Cycle through the quiz until all pairs are matched or the host ends the game. Start each new pass using the lobby's shuffle settings and continue filling the current question phase. With eight questions, the third phase uses questions seven and eight and the first question of the next pass.

## Reveal phase

Each player in the turn order takes one reveal turn per pass. Continue in the same order, skipping players who have no chips, until everyone runs out. Then return to the question phase if the board still has cards.

A reveal turn gives the player 15 seconds to confirm two distinct cards. A player who reconnects may confirm before the original deadline. Confirming a pair spends one chip and reveals both faces. An expired turn always spends one chip and advances without revealing cards, including on disconnect or when the player has selected cards without confirming.

A confirmed match earns one point as soon as both faces are revealed. The matched cards stay visible for one second, then leave both spaces empty. A mismatch stays visible for two seconds before both cards turn face down again. The next player's full 15 seconds begin after the cards are removed or turned face down.

Clearing the board ends the game as soon as the final match comes off the board, even if players still have chips. A confirmed host End goes directly to the podium at any point regardless of remaining chips. A match that is still face up already counts toward the player's score. The podium ranks players by matched pairs, with equal scores sharing a place. The results sheet lists rank, player name, matched pairs, correct answers, and total time across submitted answers.

## Board and controls

The host can choose a 6×6, 8×8, or 10×10 board in the lobby. The default is 10×10 and the host's choice carries over to the next lobby. Randomly draw 18, 32, or 50 distinct face images from the theme's pool and make exactly two cards for each selected image. Shuffle the cards once at the start. Card positions stay fixed across phases.

During questions, phones use the standard paced question and answer view. The host uses the standard paced controls, and either manual or automatic advance can start the reveal phase after the third question. Reveal turns advance automatically.

During the reveal phase, phones prompt spectators to look at the projector. The active player's phone opens each turn with the full board in view, showing card backs and empty spaces. The player can drag and pinch to zoom as in Land Grab. They start with no selections, tap again to deselect a card, and must deselect one before selecting a third. A separate button confirms their two selections. The projector shows the revealed faces.

The projector shows whose turn it is above the board and each player's matched-pair score to the right. The Christmas theme groups the wooden table, winter card back, and 50 distinct Christmas card face images together. Add a theme picker when another theme is available.
