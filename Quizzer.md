Requirements:
* Setup a quiz style game.  Enter in new question/answers for quizzes.
* When the quiz is started, it is presented by a host computer that will have a projector or large display.  That display will give the question and answer options.  It will also give join instructions to all the clients that may connect.
* Each quiz needs to be able to be joined by students on their mobile phones.  They can join through their browsers with a QR code that they can scan from the host screen, or with a URL that will be displayed.
* Multiple quizzes can be stored at once, and allow quizzes to be added or removed later.
* Quizzes can be created and edited by an AI agent through an MCP or skill that will be created.

Quiz Requirements:
* Quizzes need to have the following question types:  Multiple choice and True/False
* Once all answers are in, each client screen needs to show If they got it wrong or right.  If they got it wrong, the correct answer needs to be highlighted.

Host Requirements:
* This needs to be able to run on both Linux and Windows.

Restrictions:
* This needs to work without a domain name over the internet.  It is possible for it to work over a local LAN
* Nothing can be installed on the client phones
