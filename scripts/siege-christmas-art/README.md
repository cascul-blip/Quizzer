# Christmas Toybox production artwork

Generated with the built-in image_gen tool using the approved Christmas Toybox concept. Original PNG sources are preserved here. Run `python3 scripts/siege-christmas-art.py` from the repository root to prepare the WebPs and animation manifest. Conversion requires Pillow and numpy.

The existing combat timing, game rules, effects, poses and animation classes are retained. Knight and giant layers use Toybox-specific pivots in the generated manifest. All pose pairs share a base width and anchor. The background is aligned to the original five-lane hit grid. Phone icons are prepared independently at 128px. Level 3 uses the existing gold glow; generated gifts, candy canes and pennants distinguish upgrades.

## Prompts

The current castle uses the three connected towers along the left side, replacing the original flat wall. Versioned sources and exact generation/edit prompts are documented in [castle-left-prompts.md](castle-left-prompts.md).

The v4 [camera correction](castle-camera-prompts.md) replaces the shallow portrait view with a higher camera angle and registers the full wall footprint to the board's back and front edges. The earlier v3 [alignment correction](castle-alignment-prompts.md) is retained as source history.

The current v5 [left-rim correction](castle-rim-prompts.md) keeps that high camera and full depth, moves the far and middle sections left to meet the board's side, and preserves the foreground tower position.

Troll pose alignment measures contiguous opaque base spans so the lowered hammer is excluded. Its 330×300 canvas provides left-side clearance for the full-size attack; the runtime reads its size and anchor from the generated manifest.

The final collapsed castle removes the unsupported upper battlements so only grounded rubble remains. Refinement prompt:
