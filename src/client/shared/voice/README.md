# Voice clips

The four original robot MP3s are the existing Sovereign takes.

## Active snowman recordings

These clips use the same processing as the approved `snowed-by-the-snowman.mp3`
trial: mono, input sample rate interpreted as 34400 Hz, resampled to 44100 Hz,
1.12× tempo compensation, 70 Hz high-pass / 6500 Hz low-pass, a parallel
220–3300 Hz softly saturated layer (gain 3, tanh threshold/output 0.55,
37 Hz tremolo depth 0.25, blended at 0.28), +3 dB bass EQ at 155 Hz,
compression, a short 38 ms echo, and -16 LUFS / -2 dBTP normalization.
Encoded as 160 kbps MP3. Originals in Documents are unchanged.

| File | Trigger |
|---|---|
| `lookwarm.mp3` | Target-lock warning, after the alarm and before the attack |
| `frostyaim.mp3` | Attack misses everyone |
| `coldispatient.mp3` | Attack hits players without eliminating anyone |
| `thawout.mp3` | Attack eliminates someone, including attacks with surviving hits |

The earlier trial line is no longer used. The robot skin keeps its original
four recordings. Existing timing, voice controls, and music ducking are preserved.
